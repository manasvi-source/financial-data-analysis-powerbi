# 📊 Financial Data Analysis Dashboard – Power BI

## 📌 Project Overview

An interactive Financial Data Analysis Dashboard developed using Microsoft Power BI to analyze sales performance, revenue, profit, discounts, products, countries, and customer segments.

The dashboard provides a consolidated view of key financial metrics and enables users to explore business performance through interactive filters and visualizations.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

## 📊 Key Performance Indicators

- Number of Sales: 700
- Total Units Sold: 1.13M
- Total Discounts: 9.21M
- Total Gross: 127.93M
- Total Revenue: 118.73M
- Total Profit: 16.89M
- Average Manufacturing Price: 96.48

## 📈 Dashboard Features

- Sales analysis by customer segment
- Country-wise sales analysis
- Product-wise sales performance
- Sales by discount band
- Revenue and profit analysis
- Total units sold analysis
- Gross sales analysis
- Interactive filtering by:
  - Segment
  - Country
  - Product
  - Discount Band
  - Date

## 🔍 Key Insights

- Government is the highest-performing customer segment by sales.
- Paseo is the top-performing product based on sales.
- Medium discount products contribute a significant portion of sales.
- The dashboard provides geographical analysis of sales across different countries and regions.
- Interactive filters allow users to analyze financial performance based on different business dimensions.

## 🎯 Project Objective

The objective of this project is to transform financial and sales data into an interactive Power BI dashboard that helps users monitor key performance indicators, identify sales trends, compare product and segment performance, and derive meaningful business insights.
